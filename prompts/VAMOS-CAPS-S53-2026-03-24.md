## CONTEXT — WHAT WAS LOST

### 1. The Reveal (MEGA-FINISH sprint, March 16)
The original design was:
- Full-screen reveal per board — one board at a time takes the whole screen
- Large "BOARD 1 OF 4" title
- Community cards large and centered
- Player's 4 cards for this board: large, labeled "YOUR CARDS"
- Bot's 4 cards for this board: large, labeled "BOT"
- Turn card flips first (400ms rotateY) → pause 300ms → river card flips → pause 200ms
- Hand name appears: "FLUSH" / "TWO PAIR" etc — large, centered, with color
- Win/lose banner: large W or L with color glow
- Chip result: "+25" or "-25" animated float
- Board progress dots at bottom: ● ● ○ ○
- Auto-advance after ~2s OR tap to advance
- TOTAL drama per board: ~2.5s. For 4 boards = ~10s of suspense.

Current state: SafeRevealOverlay shows all boards simultaneously in compact view — no drama, no flip, no board-by-board focus.

### 2. Hand Hint During Arrangement
`utils/handHint.ts` computed the strength of the hand you were building as you placed cards.
During arrangement phase, each board showed:
- What hand you currently have on that board: "Flush Draw", "Two Pair", "Straight Draw"
- Shown as a small subtitle under the board
- Updated live as you placed each card
- Helped the player make strategic decisions

### A2. Create `components/BoardReveal.tsx` — single board reveal component

Props:
```typescript
interface BoardRevealProps {
  board: BoardState;           // the board data
  boardIndex: number;          // 0-based
  totalBoards: number;         // 2, 3, or 4
  result: BoardResult;         // winner, playerHand, botHand, pot
  onAdvance: () => void;       // called when this board is done
}
```

Layout (full screen):
```
┌─────────────────────────────────┐
│        BOARD 2 OF 4             │  ← title, centered, gold
│  ● ● ○ ○                        │  ← progress dots
│                                 │
│  [Community Cards — large]      │  ← 5 cards, center
│  flop visible, turn+river face-down → flip on sequence
│                                 │
│  YOUR CARDS                     │  ← label
│  [4 cards — large row]          │  ← player's cards for this board
│                                 │
│  BOT                            │  ← label
│  [4 cards — large row]          │  ← bot cards, face-down until result
│                                 │
│  [hand name badge]              │  ← "FLUSH" — appears after river
│  [win/lose chip result]         │  ← "+25" or "-25" — appears after hand
│                                 │
│  [tap anywhere to skip]         │  ← small hint, fades
└─────────────────────────────────┘
```

Reveal sequence per board:
1. Mount: turn card faceDown=true, river card faceDown=true, bot cards faceDown=true
2. After 600ms: flip turn card (faceDown → false) + play cardFlip sound + light haptic
3. After 300ms: flip river card (faceDown → false) + play cardFlip sound + light haptic
4. After 400ms: flip all bot cards simultaneously + medium haptic
5. After 300ms: show player hand name badge (fade in from below, RN Animated)
6. After 400ms: show win/lose result + chip delta (scale in, RN Animated)
   - WIN: green glow, "+[pot]" gold text
   - LOSE: red, "-[pot]" red text
   - TIE: neutral
7. After 1200ms: auto-advance to next board (call onAdvance)

Tap anywhere = skip to step 7 immediately (clear all timers, show everything, advance after 400ms).

All setTimeout timers stored in `useRef<ReturnType<typeof setTimeout>[]>`, cleared on unmount.
ZERO Reanimated in this component — RN Animated only for fade/scale, Card.tsx handles its own rotateY.
