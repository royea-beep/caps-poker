## ⚠️ Nav verified by CODE, not pixels — stated plainly
The live browser loop **did not run in the container.** Two independent blocks, both pre-existing and
unrelated to this ship: (1) the app does not mount in this container's Chromium — the repo-documented
`import.meta` bootstrap failure (`utils/devRevealFixture.ts:27`) hits both the Metro dev server and a
local production export; (2) the agent proxy resets Chromium's direct navigation to the live domain
(`ERR_CONNECTION_RESET`), so the deployed site could not be rendered here either. **I attempted a
render at one width and could not** (item 3.2). So the 3-tab bar and the `<375` label-hide boundary are
verified **by reading the layout logic** (`tabBarShowLabel: SCREEN_W > 375`, unchanged; friends/cups
dropped via `href:null`), **not by pixels.** The merge does not imply a pixel pass. That tap is Roye's.
