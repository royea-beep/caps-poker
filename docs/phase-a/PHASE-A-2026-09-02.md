## 3 — RETURN NOTIFICATIONS  ✅ delivered + mechanism verified
- **Permission timing fixed (was a real bug):** launch called `registerAndSavePushToken()` which
  prompts — i.e. the OS notification dialog appeared **on first launch**. Changed the launch call to
  `registerPushIfGranted()`, which registers the token **only if permission is already granted** and
  NEVER prompts. The ask now happens at a **good moment**: on foreground **after the player has
  played a hand** (`handsPlayed > 0`), at most once (AsyncStorage-guarded) — never on first launch.
- **Day 1 + Day 3, and only those:** `scheduleReturnReminders()` schedules two local notifications —
  day 1 (24h) and day 3 (72h) — cancelling the prior pair each session, and `cancelReturnReminders()`
  clears them when the app opens. Wired into the `_layout.tsx` AppState handler (arm on background
  after playing; clear + prompt on foreground).
- **True on arrival + specific:** copy is tied to the daily-reward faucet (resets daily) and the
  player's persistent chips, so it holds whenever it fires — day 1: "Your daily reward is ready 🎁 /
  A fresh stack of chips is waiting"; day 3: "Still dealt in? 🃏 / Your chips — and a fresh daily
  reward — are waiting." No streak claim (that is only true for some players). **Bilingual** (shows
  in the player's language).
- **`send_push_notification` works — established, not assumed:** it looks up a bilingual
  `push_templates` row, fills `{vars}`, and writes a `push_log` row (it does **not** itself deliver to
  a device). Called it live with a synthetic user + the `daily_bonus` template → `{ok:true,
  title:"Daily Bonus Ready!", body:"Your daily chips are ready to collect 🎰"}`; **no real binding
  touched**; the test `push_log` row was **deleted** — verified `leftover_push_rows = 0`.
- **Note for the follow-up:** the existing home `daily_reward` (24h) local notification overlaps the
  new day-1 slightly; consolidate into the day-1/day-3 pair when index.tsx is next touched (left alone
  this pass to avoid conflicting with the Hebrew work).
