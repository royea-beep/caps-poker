## Architecture Decisions

| Decision | Reason |
|----------|--------|
| `newArchEnabled: false` | New Architecture breaks react-native-tcp-socket + other libs in SDK 55 |
| `Platform.OS === 'web'` not `typeof window` | More reliable, avoids SSR false positives |
| navigateRef pattern | Avoids stale closures in useEffect dependency arrays |
| `cd dist && vercel --prod --yes` | Correct deploy path — NEVER web-dist/, NEVER FTP |
| `npx expo export --platform web --clear` | --clear required to avoid stale bundle serving |
| FriendsBg web-only | No react-native-svg installed — SVG data URI in `<img>` only works on web |
| Module-level tagline counter | Persists across re-renders within app session, resets on full reload |
