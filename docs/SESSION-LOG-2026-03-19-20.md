## Key Bugs Found and Fixed

| Bug | Root Cause | Fix |
|-----|-----------|-----|
| BugReporter silent failure | `process.env.EXPO_PUBLIC_SUPABASE_URL` undefined in managed workflow | Read from `Constants.expoConfig.extra` |
| Spades invisible on card | `SUIT_COLORS_4.spades = '#000000'` (pure black = too dark on shadow, invisible in some contexts) | → `'#1a1a2e'` (dark navy) |
| Bot takes 5–30s | `botSpeedMin: 5000, botSpeedMax: 30000` in config | → `1500, 4000` |
| VersionBadge shows `?` on web | Read `ios.buildNumber` which is undefined on web build | → Read `extra.buildNumber` first |
| Web shows no splash | `useState(Platform.OS === 'web')` = `useState(true)` skips splash | → `useState(false)`, isWeb flag inside SplashOverlay |
| WhatsApp forwarded messages 400 | Twilio wraps forwarded messages differently | Added `OriginalRepliedMessageSid` header check |

## Key Decisions Made

| Decision | Reason |
|----------|--------|
| Rule 2 UNLOCKED: landscape support | User requested for TV/tablet play |
| Visual theme system token-based | Allows theme switching without touching individual components |
| `getTheme(null)` returns classic | Safe fallback during first launch before theme chosen |
| Worklet colors hardcoded (#c9a84c) | Reanimated worklets cannot read React state — acceptable design tradeoff |
| Five-O vertical layout in RevealSequence | Better use of vertical space, community cards readable alongside hands |
| `credentialsSource: remote` | Eliminates CI cert management entirely |

## Surprises / Gotchas

1. **Twilio SandboxChannels API doesn't exist** — docs mention it but returns 404. Webhook must be set via Console UI.
2. **sql.js needs array params** — unlike better-sqlite3, `stmt.run([p1, p2])` not `stmt.run(p1, p2)`.
3. **expo-splash-screen is web no-op** — had to build custom React overlay.
4. **react-native-confetti-cannon was already installed** — found it in package.json, no install needed.
5. **Hermes has `window` global** — `typeof window` check fires on native with Hermes.
6. **`entering=` in Modal freezes iOS** — Old Arch limitation.

---

## Architecture Insights

1. **rv() pattern is essential for Expo web** — without it, every component needs manual breakpoint logic.
2. **Zustand partialize is underused** — explicitly listing persisted fields prevents hydration bugs and keeps storage clean.
3. **pre-calc during countdown = free perf** — zero-wait navigation feels premium with zero actual optimization cost.
4. **Token system > hardcoded colors** — switching from `COLORS.gold` to `theme.accent` everywhere made multi-theme trivial.
5. **Multi-project WhatsApp bot** — one Edge Function for 8 repos is much cleaner than one per project. Keyword detection is reliable enough.
