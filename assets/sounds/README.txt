Sound Effects for Caps Poker
============================

Place MP3 files in this directory with these exact names:

- cardPlace.mp3  — played when a card is placed on a board
- cardFlip.mp3   — played at the start of each board reveal
- chipsWin.mp3   — played when chip counting animation starts on summary
- complete.mp3   — played when the COMPLETE overlay appears

Files are optional — missing files are silently skipped.
Toggle sound on/off in Settings > Sound Effects.
